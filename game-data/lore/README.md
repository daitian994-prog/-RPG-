# 艾欧尼亚世界观知识库

本目录保存可供后端检索的事实性摘要，不复制《英雄联盟宇宙》的故事正文，也不混入皮肤平行宇宙。

## 数据组成

- `region.json`：区域总览、自然规则、人文社会和当前冲突。
- `champions.json`：官网艾欧尼亚页列出的 23 名英雄档案、人物动机、能力、故事弧和相关人物。
- `places.json`：关键省份、村落、寺院、岛屿、要塞与精神地点。
- `factions.json`：均衡教派、影流、纳沃利兄弟会、朔极、无极等组织。
- `timeline.json`：只使用官方可确认的相对顺序；没有官方日期时明确标为年代未知。
- `relationships.json`：人物之间的亲属、师徒、同盟、敌对和内在共体关系。
- `sources.json`：Riot 官方地区页、英雄页、传记、短篇与漫画入口。

## 生成规则

`LoreService.context_for_event()` 根据当前 Demo 地点、事件类型和正文中明确出现的人名进行检索。返回上下文默认不超过 1600 字符，并禁止 AI 让未被事件点名的英雄随机登场。

## 维护原则

1. 新资料必须保留官方来源 URL。
2. 不为时间线编造精确纪年。
3. 区分已确认事实、角色观点和合理但未确认的关联。
4. 官方改写英雄传记后，更新摘要和 `updated_at`。
